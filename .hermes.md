## Arquitetura de Telas
- **Tela 1:** Video loop + carrossel de 3 amps (Lonestar/Soldano/JP-2C) com swipe vertical
- **Tela 2:** Interface de configuração (swipe horizontal entre sub-painéis)
- **Tela 3:** Outra interface (swipe horizontal)
- Transição entre telas via gesture no touch GT911

## Módulo Carrossel (app_main.c)
```c
amp_img[3] = {&lamp_lonestar, &lamp_soldano, &lamp_jp2c};
amp_set_x/y() → lv_obj_set_pos + animação
arranjar_carrossel() → reposiciona 3 amps baseado em amp_atual
d==0 → centro (400,275), d==-1 → esquerdo (140,175), d==+1 → direito (660,175)
```

## Touch GT911
- Configuração em `src/bsp_touch.c`
- `swap_xy=1, mirror_x=1, mirror_y=0`
- X_max=BSP_LCD_H_RES(800), Y_max=BSP_LCD_V_RES(480)
- Zonas definidas em `include/tela2.h` (verificar se existe)

## Display
- ST7701, 480x800 nativo → landscape 800x480 via swap_xy + rotação
- Loco de frame buffer no PSRAM (configurar via menuconfig)
- Backlight via LEDC PWM

## WiFi
- Componente `esp_wifi_remote` para comunicação ESP-NOW TX→RX
- MAC destino: 80:F3:DA:63:51:90
- Packet format: `{uint8_t cmd; uint8_t bank; uint8_t fxMask; uint8_t ch; uint32_t seq}`
- Regra: NÃO mexer sem ordem direta do usuário

## FLUXO: PROTOTIPAGEM WEB → LVGL (nova)
Quando criar tela nova ou redesignar existente, preferir este fluxo:

1. **HTML prototype** — arquivo HTML auto-contido com CSS flexbox/grid, paleta OldSkull, assets reais
   - Ferramentas: `claude-design` (design process), `sketch` (variants lado a lado)
   - Verificar no browser com `browser_exec` antes de portar
2. **Traduzir HTML→LVGL** — usar tabela CSS↔LVGL definida na skill `lvgl-prototipagem-web`
   - Cada elemento HTML vira chamada LVGL equivalente (pos, size, style, color)
   - Seguir estrutura existente (`app_main.c`, `palco.c`) — patches cirúrgicos
3. **Build + flash + testar hardware** — validar visualmente no display real

Ganhos: iteração 10x mais rápida (minutos vs horas recompilando C). Menos ciclos build-flash-teste.
Limitação: NÃO existe parser automático HTML→LVGL C — tradução sempre manual.
Referência specs: `software-development/embedded-ui-to-web/references/oldskull-specs.md`
